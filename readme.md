# PoE2 Tools

Just another PoE2 tool.

This is a small hobby project I'm building for fun while playing Path of Exile 2. It collects a few simple tools and references that I find useful while playing, without trying to become a full-blown build planner or game database.

Currently includes:

- **Rush to Maps** — a simple campaign checklist for getting a character through the acts and into maps.
- **SSF Reference** — a quick-reference guide for SSF farming, campaign progression, and early endgame decisions.

Everything is static and runs in the browser. Data is stored locally where applicable, with no account or backend required.

Built because I play PoE2 and felt like making a tool for it.
